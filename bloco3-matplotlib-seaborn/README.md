# Bloco 3 — Matplotlib + Seaborn

**Projeto:** IC-FAPEMA — Detecção de capacetes em motociclistas via drone

## O que é este bloco

Matplotlib e Seaborn são usados para visualizar imagens, desenhar bounding boxes e analisar os resultados do modelo treinado.

| Biblioteca | Para que serve no projeto |
|---|---|
| **Matplotlib** | Visualizar imagens, desenhar bounding boxes, plotar curvas de treino |
| **Seaborn** | Matriz de confusão visual, distribuição do dataset, comparação de métricas entre modelos |
