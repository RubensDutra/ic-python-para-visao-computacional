**Projeto:** IC-FAPEMA — Detecção de capacetes em motociclistas via drone

NumPy é a base de todo projeto de visão computacional. Aqui você aprende como imagens são representadas como arrays numéricos — o formato que o YOLO e qualquer outro modelo de ML esperam receber.
